# Lumyrinth

**Find your rhythm.**

Lumyrinth is a private, offline-first Android breathing companion for calm, focus, rest, and quick resets. It is built with Kotlin and Jetpack Compose.

## Features

- Guided breathing sessions with six preset rhythms
- Custom breathing rhythms with V1-safe timing limits
- Original offline ambience: Rain, Night, Ocean, Forest, Fireplace, Stream, and Deep Space
- Soft sound and haptic phase guidance
- Local-only preferences, custom rhythms, sessions, and progress
- No account, advertising, analytics, cloud sync, or subscription

## Stack

- Kotlin + Jetpack Compose
- Room + DataStore
- Media3
- WorkManager
- API 26+ / target API 37

## Run locally

Open this directory in Android Studio, allow Gradle to sync, then run the `app` configuration on an Android emulator or device.

## Play Store materials

Submission assets, store-listing text, Data safety notes, and the privacy-policy template are in [`play-store/`](play-store/).

## Important

Lumyrinth is for general wellness and breathing practice. It is not a medical device and does not provide diagnosis or treatment.
